# 类生存者 · 试玩版

一个俯视角 **类生存者（Survivor-like）** 小游戏：自动攻击、边走边打、捡经验球升级、每级三选一宝物，活过 15 波。

> 本仓库**只放可玩的试玩包与更新说明**，游戏源码不在这里。
> 引擎：Cocos Creator 3.8.8 ｜ 开发：单人原型阶段

---

## 下载游玩（Windows）

1. 打开本仓库右侧的 **[Releases](../../releases/latest)** 页面
2. 下载最新的 `survivor-game-试玩版.zip`（约 25 MB）
3. **解压后**双击 `survivor-game.exe` 即可，免安装

> 系统要求：Windows 10 / 11 64 位。
> 注意：exe 旁边的 `Resources` 文件夹和那些 `.dll` 不能删，整个文件夹要一起保留。
> 首次运行若提示缺少运行库，装一下微软官方的 **VC++ 2015-2022 运行库（x64）** 即可。

## 操作

| 操作 | 方式 |
| --- | --- |
| 移动 | 键盘 **W A S D**（或方向键）；也可以**按住鼠标左键在画面上拖动**当摇杆用 |
| 攻击 | 自动，你只管走位 |
| 升级选择 | 点击弹出的卡片，或按键盘 **1 / 2 / 3** |
| 暂停 | **ESC** 或右上角"暂停"按钮 |

## 玩法

- 每局 **15 波、每波 30 秒**，敌人从四面围过来
- 击杀掉经验球，捡球升级 → **每次升级从三个宝物里选一个**
- 宝物规则：**第一次抽到 = 获得该宝物；之后再抽到 = 给它升级**（等级越高效果越强）
- 地图上的废料堆、机器台是**真实障碍物**，可以贴墙走位拉扯
- 死亡或通关后按空格/点按钮可以重新选角色再来一局

## 当前版本 v0.3.1 内容

- **3 个可操作角色**：赤星（扇形剑）/ 千钧（震荡榴弹）/ 沧隼（穿透光束），各有专属被动
- **7 种敌人**：赤瞳蛾、铁角甲虫、蚀铁蚁已有正式美术；其余 4 种还在做

- **掉落物**：7 档经验球（白→绿→蓝→粉→紫→橙→红）、金币、医疗包，全部正式美术
- **操作**：摇杆 + 键盘 WASD 双操作，帧率不设上限
